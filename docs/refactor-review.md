# 重构评估与小程序迁移

日期：2026-11-06。业务基线为 `origin/agent/ce19a653`（`5e59cdc`），工作分支为 `codex/refactor-news-ui`。`main`（`94f088a`）仅有初始化代码，不代表完整业务。

## 当前结论

原项目不是 Taro 工程，而是 Next.js 与多套并存的后端实现。核心问题是业务代码、页面与运行入口耦合，以及一些经过单测的模块没有真正接入启动流程。本次将阅读端迁移至 Taro，后端独立保留，并修复默认采集入口。

## 设计说明

- 今日：重点资讯后接短摘要列表；分类横向滑动，搜索入口进入组合筛选。
- 发现：按主题和来源探索，不加入没有后端支撑的关注、收藏或登录功能。
- 搜索：关键词、来源、分类、日期组合筛选；切换条件回到第一页；日期按北京时间解释。
- 详情：标题、来源、时间与摘要分层；底部固定分享/复制原文，适配安全区。
- 状态：空数据、无匹配、加载、网络失败、文章不存在、摘要待处理/失败均明确表达；示例不冒充真实资讯。
