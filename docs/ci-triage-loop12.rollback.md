# Loop 12 回滚要点

- 共享模块（归一化/相似度/分页元数据/摘要截断/arxiv 解析）改动合并前，先确认调用方只有本仓库内的 App Router 页面与 API 路由，无外部消费者。
- 归一化语义变更不可回滚历史数据：`normalized_url` 已按旧口径落库的行不会被自动重算；如需重算，走一次性脚本按主键分批 `UPDATE`（每批 ≤1000 行），不得整表重写。
- 页面渲染方式变更（Response → JSX）属纯代码回滚，无结构变更，回滚即回到上一版本应用镜像。
- 回滚后必须重跑 `npm run typecheck && npm run build && npm run test`，不接受「只回滚一部分代码但结构已变」的中间态合入主干。
