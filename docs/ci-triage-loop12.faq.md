# Loop 12 附：为什么不能只改测试

- 三处断言互斥（非 http(s) 的归一化结果、路径尾斜杠、空集 `totalPages`），只改一侧会让另一侧变红；必须先在 `docs/news-primitives.md` 冻结语义，再统一实现，最后把偏离契约的断言对齐。
- 放宽标题相似度阈值可以让 `api-news.part10` 变绿，但会直接违反 AC3（重复率 < 1%），故只允许改夹具。
- 在页面文件里返回 `Response` 可以让接口用例通过，但与 Next.js 16 App Router 的 page 契约冲突，必须改渲染方式而不是绕过类型校验。
- 本轮未执行任何命令，任何「已通过」的说法都不成立。
